# 天下势力与灵根品级更新

## 已实现

### 灵根双维度
- 灵根类型与灵根品级彼此独立。类型继续决定战斗倾向与基础修炼速度；品级决定额外修炼倍率和突破成算。
- 品级从一品至九品，一品最高、九品最低。新角色独立随机品级，当前概率：一品 0.2%、二品 0.6%、三品 1.7%、四品 3.5%、五品 6%、六品 10%、七品 14%、八品 22%、九品 42%。
- 灵根品级随角色存档保存；旧存档自动补为九品，不破坏已有角色。
- 新增“灵根蜕变”奇遇：可提升一品、改变灵根类型并保留原品级，或放弃机缘。
- 灵根品级影响修炼效率与突破成算；灵根类型仍决定攻防、功法威力、暴击、闪避等战斗特性。

### 多方势力
- 建立青岚剑宗、大虞皇朝、百草谷、天机世家、万妖盟、九幽魔宗、散修盟七方势力。
- 玩家开局默认为散修，可从“探索与储物 → 天下势力”查看势力、加入或退出。
- 势力归属、身份、贡献、声望、关系与世界冲突计数写入存档；旧存档兼容默认散修。
- 游历时有概率触发天下风云消息，呈现宗门争灵脉、皇朝征召、妖盟扩张、世家争夺洞天等多方冲突。
