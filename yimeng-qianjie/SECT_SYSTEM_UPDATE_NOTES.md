# 宗门系统更新说明

本次在既有天下势力框架上，加入可实际参与的宗门日常与成长玩法。

## 已实现

- 宗门与魔宗成员识别：青岚剑宗、百草谷、九幽魔宗可使用宗门内务；皇朝、世家、妖盟和散修盟仍使用原势力身份逻辑。
- 宗门身份晋升：外门弟子、内门弟子、真传弟子、执事、长老、太上长老、宗主。晋升同时检查累计宗门功绩与当前境界。
- 宗门任务：巡山除妖、采集灵药、护送商队。完成后获得灵石、贡献，并可能获得材料或因果奖励；每三次行动可领取一次。
- 宗门供奉：消耗灵石换取贡献与累计功绩。
- 宗门宝库：消耗贡献兑换聚气散。
- 聚灵设施：最高三级，升级消耗灵石与贡献；每级额外增加 2.5% 修炼效率。
- 存档兼容：累计功绩、设施等级、任务领取时间均写入存档；旧存档会自动补默认值。
- 离开势力时清空该宗门的贡献、功绩与设施进度，避免跨宗门继承宗门资产。

## 数值

| 项目 | 规则 |
|---|---|
| 供奉 | 50 / 200 / 500 灵石，按每 2 灵石获得 1 贡献 |
| 宗门任务 | 28 + 当前境界序号 × 3 贡献；18 + 当前境界序号 × 5 灵石 |
| 宝库兑换 | 35 贡献兑换 1 份聚气散 |
| 聚灵设施 | 1级：120灵石+40贡献；2级：220灵石+70贡献；3级：320灵石+100贡献 |
| 修炼加成 | 每级 +2.5%，最高 +7.5% |

## 第二阶段：弟子与藏经阁

- 新增门下弟子名册，最多收录五名弟子；玩家晋升执事及以上身份后可招收弟子。
- 招收弟子会生成姓名、灵根类型、九品至三品的灵根品级、资质、初始忠诚度等数据，并消耗灵石。
- 可消耗灵石亲自教导弟子，提升修炼进度与忠诚度；修炼进度满百后弟子境界提升。
- 新增藏经阁入口，展示当前战斗系统已有功法；按弟子、内门、真传、长老等身份限制可阅览的功法阶位。
- 研习功法同时消耗灵石和宗门贡献，学会后可在原有功法界面装备。
- 新增弟子与招收次数存档字段，旧存档自动兼容为空名册。
