# 宝物与旧物功能更新

本次更新基于上一版分组菜单工程：

- 储物袋增加「宝物」分类；该分类汇总角色持有的全部 `treasures`，不会遗漏装备、可启用宝物或剧情旧物。
- 「装备」和「特殊」仍可单独筛选。
- 宝物条目增加「详情」按钮，可查看描述、来历、品阶与佩带信息。
- 为无名玉简、长生铜钱、半部道经、前世糖人、天外星石、灵泉玉鱼、念字玉扣、旧剑穗、崖畔剑意增加每世一次的主动灵韵效果。
- 主动效果使用 `GameState.flags["used_treasures"]` 保存，沿用现有存档 `flags` 字段，不需新增存档字段。
- 无主动效果的旧物仍可查看详情，保留为剧情/收藏物品，不会被错误显示为可使用。
- 修正背包在已打开弹窗中切换分类或使用物品后重新打开时的状态判断。

注意：本环境未检测到 Godot 可执行程序，已做代码文本检查和 ZIP 完整性检查，尚未进行 Godot 编辑器导入及运行测试。
